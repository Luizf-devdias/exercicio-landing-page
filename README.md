# 🚀 **Landing Page de Agência — Modelo Responsivo**

> Uma landing page elegante, moderna e 100% responsiva para agências (ou qualquer outro tipo de negócio)!  
> Criada com carinho usando apenas **HTML5 + CSS3**, com foco total em layout clean e estrutura organizada.  
> **Flexbox** + **Grid** = combinação perfeita! 💡✨

## 🛠️ **Tecnologias Utilizadas**

- 💻 **HTML5** — estrutura semântica e bem organizada  
- 🎨 **CSS3** — estilização moderna e responsiva  
- 📐 **CSS Grid Layout** — para criar o layout principal  
- 📦 **Flexbox** — para alinhar e distribuir os elementos internos  

---

## 📱 **Responsividade**

O layout se adapta perfeitamente a diferentes tamanhos de tela:  
✅ Desktop  
✅ Tablet  
✅ Mobile  

Tudo feito na unha, sem frameworks ou bibliotecas externas. 🧠💪
